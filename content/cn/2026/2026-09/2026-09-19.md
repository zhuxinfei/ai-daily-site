### 🟢 前沿研究

1. **FAMOS（从稀疏观测直接建立三维关节运动模型）探索少量数据下的三维建模。**
这项研究关注如何从**稀疏观测**（只看到少量视角、画面或状态，而非完整记录）中，还原物体的三维结构与关节运动。它采用**前馈式建模**（输入数据一次通过模型便直接产生结果，不需要反复迭代优化）的研究思路，目标是同时处理形状与活动部件之间的关系 🦾。这类研究瞄准的核心难题是：当可用信息不完整时，模型能否依然理解物体“长什么样、哪里能动”。[FAMOS 论文页面(briefing)](https://huggingface.co/papers/2609.20817)

![Paper page - An Empirical Study of Harness Design for Coding Agents](https://cdn-uploads.huggingface.co/production/uploads/616bfc2b40e2f69baa1c7add/XBQHJFtdMcw0MCgY9Ddwo.png)

2. **编程智能体的“外部运行框架”该怎么设计？一项实证研究开始拆解。**
论文研究的是**运行框架**（包裹在智能体外部、负责提供工具、反馈和执行规则的系统）如何影响编程智能体，而不只是比较模型本身。所谓**实证研究**，是通过实际实验和数据观察设计差异，而非只做理论推演 🔍。这意味着，评估编程智能体时不能只看底层大模型，还要留意它获得了什么工具、如何接收反馈，以及任务如何被组织。[编程智能体框架论文(briefing)](https://huggingface.co/papers/2609.20804)

3. **RetireOPD（可自行停止蒸馏的智能体强化学习方案）尝试让训练适时“收手”。**
这项研究提出面向智能体强化学习的**同策略蒸馏**（学生模型用自己当前策略产生的数据，学习更强模型或目标策略的能力）。其中“自行停止”指向一种可退出蒸馏过程的设计，重点是不让蒸馏环节无限持续 🔄。**智能体强化学习**（让 AI 通过执行任务和获得反馈来改进决策）通常包含较长的训练流程，因此何时继续、何时退出是值得研究的训练问题。[RetireOPD 论文页面(briefing)](https://huggingface.co/papers/2609.20784)

4. **自我演进搜索索引，让检索系统尝试边用边调整。**
论文聚焦**搜索索引**（把资料预先整理成便于快速查找的结构，类似给大型档案库制作目录）如何实现自我演进。这里的**自我演进**指索引不是长期固定不变，而是能够随信息或使用过程进行调整 📚。研究标题指向一个重要方向：除了提升负责回答问题的模型，也可以改造模型查找资料时依赖的底层“目录”。[自我演进索引论文(briefing)](https://huggingface.co/papers/2609.19656)

5. **结束标记出现分歧，可能带来模型回答“越说越长”的问题。**
论文研究**结束标记**（模型用来判断一句话或一次回答应该在哪里停止的特殊信号）不一致时，与输出长度膨胀之间的关系。研究场景是**同策略蒸馏**（模型基于自己当前生成的数据继续学习），其中教师与学生对“何时结束”产生分歧，可能成为分析回答变长现象的关键切口 🧩。这项工作把关注点从“回答内容对不对”延伸到了“模型能不能在合适的位置停下来”。[输出长度研究论文(briefing)](https://huggingface.co/papers/2609.20511)

6. **大模型推理并非“多生成几个答案”就够了，候选答案怎么产生同样关键。**
论文指出，在**测试时扩展**（模型回答问题时投入更多计算，多次尝试后再选结果）中，样本数量并不是决定效果的唯一因素。**候选答案生成策略**（规定模型以什么方式产出多个备选答案）还会影响性能与能源消耗 ⚡。这提醒使用方，增加计算预算不能只看“生成了多少次”，还要考虑这些候选答案是否以合适的方式产生。[推理扩展研究论文(briefing)](https://huggingface.co/papers/2609.19499)

7. **安全研究人员借助 Claude，在不到 72 小时内攻入 OpenAI 内部系统。**
报道称，安全研究人员使用 Claude 利用 OpenAI 系统中的**安全漏洞**（可能被攻击者利用的系统缺陷），并接管了员工账户。研究人员还进入了**内部代码仓库**（公司集中保存和管理源代码的内部系统），随后向 OpenAI 报告相关问题 🔐。事件显示，AI 不仅能辅助日常工作，也能加快漏洞查找与攻击操作，企业的账户权限和内部代码保护因此面临更直接的考验。[事件完整报道(briefing)](https://techcrunch.com/2026/09/18/researchers-used-anthropics-claude-to-hack-into-openai/) [安全事件详情(briefing)](https://the-decoder.com/security-researchers-used-anthropics-claude-to-hack-openais-internal-systems-in-under-72-hours/)

2. **Claude Code 现在会读取 AGENTS.md（供智能编码助手读取项目规则的说明文件）。**  
从 **2.1.277 版本**开始，如果某个文件夹里没有 CLAUDE.md（专门告诉 Claude Code 如何处理当前项目的说明文件），Claude Code 就会自动检查并使用 AGENTS.md。这个设计相当于加入了**回退机制**（首选文件不存在时，自动改读备用文件），让项目指令更容易被继续沿用 🚀。[官方更新日志(briefing)](https://code.claude.com/docs/en/changelog)已经确认这一变化，[相关引述原文(briefing)](https://simonwillison.net/2026/Sep/18/thariq-shihipar/)还明确给出了起始版本。对已有 AGENTS.md 的项目来说，这意味着 Claude Code 可以直接读取其中的规则，不必先补建 CLAUDE.md 💡。

3. **《能力悬垂》（讨论人工智能能力积累与释放的文章）认为，行业仍在指数曲线上前进。**  
作者的核心判断是，人工智能发展仍处于**指数曲线**（越往后增长越快，而不是匀速前进）之上 🚀。他通常每隔几周发布一篇文章，但随着变化节奏持续加快，这个频率也开始显得太慢。换句话说，行业信息可能在两次更新之间就迅速过时，观察者需要更频繁地重新判断局势 💡。[作者完整文章(briefing)](https://www.oneusefulthing.org/p/the-overhang)呈现了这份对发展速度的直观感受。
